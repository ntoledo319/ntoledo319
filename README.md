## Current work

### Tessera

[Tessera](https://qi.toledotechnologies.com/pci-4-compliance-scanner) turns a
bounded payment-page or email-authentication check into inspectable evidence.
The free check needs no account, and representative deliverables are public
before checkout.

- [**PCI Payment Page Script Check**](https://github.com/ntoledo319/pci-payment-page-check)
  — free MIT GitHub Action that inventories script elements in served HTML and
  can fail CI when an observed host is outside your authorization list.
- [Install it from GitHub Marketplace](https://github.com/marketplace/actions/pci-payment-page-script-check).
- [Build the reviewer-owned 6.4.3 inventory](https://qi.toledotechnologies.com/pci/pci-dss-6-4-3-script-inventory-template).

The check does not execute JavaScript, see runtime-injected scripts, decide
whether a script is authorized, or certify PCI DSS compliance. It produces
bounded software evidence for qualified human review.
